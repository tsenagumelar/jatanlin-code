# Web V3

Web revamp berada di `apps/web`. Implementasi bisa dimulai dari Next app baru atau copy selektif dari `../jatanlin-web-apps`, tetapi source lama tidak diedit.

## Direction

- V3 menjadi tampilan utama, tetapi route revamp tidak memakai prefix `/v3`.
- UI existing v3 menjadi acuan style, layout, dan flow.
- Route lama hanya referensi.
- Semua route sidebar v3 harus valid.
- State/data layer dirapikan agar mudah dites.
- Module source tetap boleh bernama `src/modules/v3` untuk menjaga jejak migrasi, tetapi URL browser harus langsung seperti `/dashboard`, `/login`, `/monitoring/processing`.

## Expected Structure

```text
apps/web/
├── app/
├── src/
│   ├── modules/
│   │   └── v3/
│   ├── components/
│   ├── lib/
│   └── styles/
└── package.json
```

## Done Criteria

- `make web-dev` menjalankan dev server.
- `make web-build` berhasil.
- Route utama revamp bisa dibuka tanpa prefix `/v3`.
- Tidak ada dependency runtime ke folder web lama.
